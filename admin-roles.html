Role reference

Owner
Full platform access. Assign/revoke any role. Cannot be granted via this panel — set in server config.
Moderator
Content moderation. Review reports, delete posts, lock accounts, send announcements. No analytics access.
Tester
Helps test new features before they go live. Access to beta features and test environments.
Analyst
Read-only statistics. Can view analytics and audit logs but cannot take any actions.
Email Writer
Can create, draft, and send community emails via the email editor. No other admin access.
