Get the Progress app

Install Progress on your device for a faster, full-screen experience with no browser bar.

1
Open Safari Progress can only be installed from Safari. If you're using Chrome or another browser, switch to Safari first.
2
Tap the Share button At the bottom of the screen, tap the Share button (the box with an arrow pointing up).
3
Tap "Add to Home Screen" Scroll down in the share sheet and tap Add to Home Screen. Then tap Add in the top right.
4
Done! Open from your home screen Progress now appears on your home screen like any other app — full screen, no browser bar.
💡 On iPad, the Share button is in the top-right toolbar next to the address bar.
1
Open Chrome Make sure you're using Google Chrome. Other browsers may not support installing apps.
2
Look for the install prompt Chrome will show a banner at the bottom or an Install button in the address bar. Tap it.
3
Or use the menu Tap the three-dot menu ⋮ in the top right, then tap Add to Home screen or Install app.
4
Tap Install and you're done Progress will appear in your app drawer and home screen.
💡 If you don't see the option, make sure you're on progressing.online and using the latest version of Chrome.
1
Open Chrome or Edge Desktop installation works in Chrome and Edge. Firefox and Safari on Mac don't support it.
2
Click the install icon in the address bar Look for a small computer or download icon on the right side of the address bar and click it.
3
Click Install A dialog will appear. Click Install and Progress opens in its own window — no browser tabs.
💡 On Mac, use Chrome for the best experience. Safari on Mac doesn't support PWA installation yet.
