Get the Progress app

Install Progress on your device for a faster, full-screen experience — no browser bar.

1
Open Safari Progress can only be installed from Safari. Switch from Chrome or another browser if needed.
2
Tap the Share button At the bottom of the screen, tap the Share button — the box with an arrow pointing up.
3
Tap "Add to Home Screen" Scroll down in the share sheet and tap Add to Home Screen. Then tap Add in the top right.
4
Done! Open from your home screen Progress appears on your home screen like a native app — full screen, no browser bar.
💡 On iPad, the Share button is in the top-right toolbar next to the address bar.
1
Open Chrome Use Google Chrome. Other browsers may not support installing web apps.
2
Look for the install prompt Chrome may show a banner at the bottom or an Install icon in the address bar. Tap it.
3
Or use the browser menu Tap the three-dot menu ⋮ in the top right, then tap Add to Home screen or Install app.
4
Tap Install and you're done Progress appears in your app drawer and home screen.
💡 If you don't see the option, make sure you're on progressing.online using the latest Chrome.
1
Open Chrome or Edge Desktop installation works in Chrome and Edge. Firefox and Safari on Mac don't support it yet.
2
Click the install icon in the address bar Look for a small computer or download icon on the right side of the address bar and click it.
3
Click Install A dialog appears. Click Install and Progress opens in its own window, no browser tabs.
💡 On Mac, use Chrome for the best experience. Safari on Mac doesn't support PWA installation yet.
